# 氷川道中

mitsulab の作品《氷川道中》（Hikawa Dochu）です。シリーズ「森羅道中」（氷川／街道／巡礼）の一作目です（旧名：森羅道中 氷川・Aoi Walk 氷川・Qualium in Hikawa・Feel Hikawa。リポジトリの名前は変えていません）。

さいたま市大宮区の氷川参道を、実寸の 3D の中で、または現地で歩きます。**人と自然のあいだに立つ依代・碧（あおい）がそばに付き添い、いまいる場所の、ふだん届いていない木や土や時間の気配を、声で手渡します。**人の知覚の外へひらかれたこの場を、mitsulab は Qualium と呼んでいます。
碧は mitsulab が AI の技術を使ってつくった依代で、人ではありません。確かめた事実（出典は設定の中）だけを話し、推測は「とみられます」、伝承は「伝えられます」と言います。木や土や場所の良し悪しは診断しません。木の気持ちを代わりに話すこともしません。お店はすすめません。

## 歩き方（2026-10-07 第16回）

歩き方は二つです。はじめの画面と、左上の ≡（設定）で選びます。

- **画面で歩く**：地面を押すと、そこへ歩いて行きます（行き先に小さな輪が出ます）。画面をなぞると、向きが変わります。PC はクリックとドラッグ、矢印キー（W S A D）も使えます。
- **現地で歩く**：位置情報を許可して始めます。**歩きながら画面を見ないでください**（イヤホンで、耳で聞いてください）。横断歩道とその前後では碧は話しません。
- **碧のしずく**：近くに碧の話せるものがあると、碧の色のしずくが浮かびます。押すと、碧が話します。真横やうしろにあるときは、画面の端に小さなしずくが出ます（押すと、そちらを向きます）。
- **時をさかのぼる物**：淡く光る物（標石・社号碑・嘉永の燈籠・二の鳥居・三の鳥居）に近づいて少し立ち止まると、その物が建ったころの景色へ。画面の下の「いまへ戻る」で戻ります。
- **かけら**：碧が示した鳥居や石、木から「かけら」が集まります（左上）。歩き終えたら、集めたかけらをならべます。
- **上の小さな地図**：参道の全体と、いまの位置・向き。点を押すと、その場所へ移ります。
- 位置は端末の中だけで使い、送らず、残しません。選んだ層・音・文字の大きさだけを、この端末に覚えます。
