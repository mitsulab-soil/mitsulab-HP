# Qualium 川越

mitsulab の作品《Qualium 川越》です。Qualium は、ひとつの場所に Qualia の層（sight・sound・touch・sho など）が重なる場で、氷川に続く二つめの場所です。

本川越駅から大正浪漫夢通り・一番街・時の鐘・札の辻・菓子屋横丁まで、およそ 1.65 km の道を、実寸の 3D の中で歩きます。蔵造りの町に、自然・歴史・文化の記録の層と、Qualia/sight・sound・touch・sho の層を重ねます。碧（あおい）がそばで、近くの記録を出典つきで話します。

公開先：<https://mitsulab-soil.github.io/aoi-walk-kawagoe/> ／ <https://mitsulab.jp/x/12/>

## 歩き方

- **はじめ**：川越の町を上空から眺め、始める地点（本川越駅・大正浪漫夢通り・仲町交差点・時の鐘・札の辻・菓子屋横丁ほか）を選んで「ここから歩く」。
- **歩く**：地面に触れるとそこへ歩きます。ドラッグで見回し、PC は W／↑ でも前へ。「歩きつづける」で道に沿って進みます。
- **飛ぶ**：上の「飛ぶ」。上へ・下へ、「地上へ降りる」で通りに戻ります。
- **層**：左の一覧で、層ごとに重ねる／外すを切り替えます（はじめは全部重ねています）。光る札に触れると開き、碧がその場所の記録を話します。
- **Qualia/sight**：イソヒヨドリ・ハクセキレイの身体に入り、いまいる所を、その鳥の高さと目の手がかりで見ます。動くのは見る人の操作だけです。
- 位置情報は使いません。外へ送るものはありません。

## 模式であること

- 通りの店蔵・町家と時の鐘の 3D は、川越の蔵造りの一般の形から mitsulab が組んだ型（模式）です。どの建物が蔵造りかを一棟ずつ写したものではありません。店名・看板・家紋・人は作っていません。私有の建物は、公道から見える外観の型だけです。
- 建物の高さは OpenStreetMap に記録がないため、面積から決めた模式です。
- 時の鐘の音は、記録にもとづいて組み立てた音（③ 再現音）で、録音ではありません。
