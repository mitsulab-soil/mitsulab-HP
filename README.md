# mitsulab HP

[mitsulab.jp](https://mitsulab.jp/) の静的サイトです。環世界を拡張する道具と体験を紹介します。

## 主なファイル

- `index.html` — 日英の本文、TOP の地理3D、碧の3D。
- `qualium-top.css`、`js/qualium-top.js`、`js/qualium-loop-3d.js` — 環世界とミッションを結ぶ点群3D。
- `vendor/` — Three.js 0.170.0 と three-vrm 3.5.5 の同版ライブラリ。各 LICENSE を同梱。
- `fonts/`、`img/` — サイト内から配信する書体・画像・地理データ・3D素材。
- `x/` — 個別アプリの配信。TOPだけの更新では他アプリを変更しません。

## 読み込みと動き

初めは地理データから点と線の実3Dを描き、スクロールに応じて詳細の地形・建物・碧を読み込みます。最初の描画と、全ての詳細モデルが揃う時刻は異なります。点群の概念図は実測や主観的体験の再現ではありません。

描画ライブラリは同じ版をサイト内から配信します。最初の点と線には Three と地理データだけを使い、モデル用ローダーは詳細モデルを求めた場面で読みます。初回は2描画フレームを譲って文字を先に表示し、実3Dの描画後に静止画を180msで切り替えます。

## 公開版の計測記録

2026-10-17、公開版 **5d0b827** を同じ Mac / Apple M5 の通常 Chromium で、新しいブラウザコンテキストを使い各3回測定しました。OS・ネットワーク・CDNのキャッシュ状態は制御していません。

- PC 1280pxの初回実3D: **4.327 / 4.353 / 5.108秒**。
- 375pxの初回実3D: **4.133 / 2.794 / 2.922秒**。
- PCの静止画opacity完全消失: **5.069 / 5.113 / 5.852秒**。
- 375pxの静止画opacity完全消失: **4.885 / 3.541 / 3.672秒**。

初回実3Dは `scene-ready`（地理の点/線を最初に描いたフレーム）、静止画消失は computed opacity が0.001以下になった時刻です。canvasは静止画の上にあるため、両者を分けて記録しています。詳細の地形・建物・碧はこの後スクロールで読み込まれます。

この時点では **全6回5秒以内は未達** です。日英表示・6段階操作・碧・停止・横溢れなど58項目は成功、JavaScript例外とHTTPエラーは0でした。次のローダー後読みと180ms切替の値は、再計測結果が確定してから追記します。回線や機種を問わない5秒保証ではありません。

## 確認と公開

HTTP サーバーで開いて確認します。PCと375px、日本語と英語、ラベル全表示、横溢れ、3Dと碧のロードを点検してください。

GitHub Pages が `main` の内容を配信します。変更対象だけを保存・commit・pushし、配信後はHTTPとSHA256の照合と実操作で確認します。外部依存を増やす場合はライセンスも記録します。
