## 概要

mitsulabは、農地劣化・斜面崩壊・森林衰退の共通根である土壌生態系の機能回復を、有機農業・有機土木・森林土木・里山管理の実践知と、AI・衛星画像・IoT・xRによる自然システムの知覚拡張という二つの柱から探求する研究所です。

## ローカルでの確認方法

VS Code + Live Server 拡張機能を使用。

1. VS Code でフォルダを開く
2. `index.html` を開く
3. 右下の「Go Live」をクリック
4. ブラウザで `http://127.0.0.1:5500` を確認
